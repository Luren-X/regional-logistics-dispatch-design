# 核心 RESTful API 接口规范与界面线框原型设计

## 1. 接口设计统一规范

* **通信协议与风格**：基于 HTTPS 的 RESTful JSON 接口，统一前缀 `/api/v1`，鉴权请求头携带 `Authorization: Bearer <JWT_TOKEN>`。
* **统一响应包装结构**：
  ```json
  {
    "code": 20000,
    "message": "success",
    "data": {},
    "timestamp": "2026-11-22T14:30:05+08:00"
  }
  ```
* **核心业务错误码定义**：
  | 错误码 | 含义说明 | 前端/调用方建议处理动作 |
  | :---: | :--- | :--- |
  | `20000` | 操作成功 | 正常渲染业务数据 |
  | `40005` | 非法运单状态跃迁（如终态不可改派） | 弹窗提示当前运单状态并刷新列表 |
  | `40901` | 并发冲突（分布式锁占用或乐观锁版本过期） | 提示“该区域正被其他调度员操作，请 2 秒后重试” |
  | `50301` | 外部地图 API 超时（接口仍返回 200，附降级标记） | 页面顶部显示弱提示：“当前路线为离线估算结果” |

## 2. 核心业务接口详细定义

### 接口 1：区域一键智能派单（`POST /api/v1/dispatch/auto-assign`）
* **调用角色**：区域调度员（`DISPATCHER`）
* **功能说明**：触发智能调度引擎，对指定网点的待派运单按所选策略生成调度方案并落库锁车。
* **请求体（Request JSON）**：
  ```json
  {
    "stationId": 1001,
    "strategyType": "SHORTEST_DISTANCE",
    "waybillIds": [50011, 50012, 50015],
    "autoConfirm": true
  }
  ```
* **响应体（Response JSON）**：
  ```json
  {
    "code": 20000,
    "message": "success",
    "data": {
      "mapDegraded": false,
      "createdTasks": [
        {
          "taskNo": "DT202611220008",
          "plateNo": "鲁A·8821D",
          "loadRateWeight": 84.50,
          "estimatedDistanceKm": 32.6,
          "waybillCount": 6,
          "routeStops": [
            { "stopSeq": 1, "waybillNo": "WB202611220011", "eta": "2026-11-22 15:20:00" },
            { "stopSeq": 2, "waybillNo": "WB202611220012", "eta": "2026-11-22 15:45:00" }
          ]
        }
      ],
      "unassignedWaybills": [
        { "waybillNo": "WB202611220015", "reason": "当前运力时间窗不足，建议跨网点借调" }
      ]
    }
  }
  ```

### 接口 2：司机在途异常一键上报（`POST /api/v1/tracking/report-exception`）
* **调用角色**：配送司机（`DRIVER`）
* **功能说明**：上报车辆故障、交通事故或严重拥堵，触发观察者事件联动（运单挂起 + 大屏红框告警 + 货主延误通知）。
* **请求体（Request JSON）**：
  ```json
  {
    "taskId": 8002,
    "vehicleId": 305,
    "eventType": "VEHICLE_FAULT",
    "currentLng": 117.092310,
    "currentLat": 36.661240,
    "description": "经十路东段右前胎爆胎，预计维修需2小时，申请救援转运"
  }
  ```
* **响应体（Response JSON）**：
  ```json
  {
    "code": 20000,
    "message": "异常已上报并通知调度中心",
    "data": {
      "logId": 990142,
      "affectedWaybillCount": 4,
      "waybillStatusUpdatedTo": "EXCEPTION_HOLD"
    }
  }
  ```

### 接口 3：异常运单就近二次改派（`POST /api/v1/dispatch/reassign`）
* **调用角色**：区域调度员（`DISPATCHER`）
* **功能说明**：检索事故点周边空闲救援车，将原任务中未签收的 `EXCEPTION_HOLD` 运单转派至接驳车辆。
* **请求体（Request JSON）**：
  ```json
  {
    "abortedTaskId": 8002,
    "rescueVehicleId": 312,
    "waybillIds": [50011, 50012, 50013, 50014]
  }
  ```
* **响应体（Response JSON）**：
  ```json
  {
    "code": 20000,
    "message": "二次改派成功，已推送至救援司机端",
    "data": {
      "newTaskNo": "DT202611220019",
      "rescuePlateNo": "鲁A·9032K",
      "distanceToAccidentKm": 2.4
    }
  }
  ```
